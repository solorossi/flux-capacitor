Flux Capacitor

This is a simple website to document the flux capacitor project, which mainly consists of a ReST service that provides time and time zone tools available in the Java Time API. These tools may be useful for programming environments that do not have access to the modern tzdata or zoneinfo IANA Time Zone Database.

Documentation for the ReST endpoints is available via the following links to an OpenAPI / Swagger generated utility. Swagger's try-it-out feature allows experimentation with the ReST endpoints without needing another tool, like Postman.
